# 🍽️ Halal Delights: A Culinary Journey 🌶️

## 🚀 Project Overview

**Halal Delights** is a modern, responsive restaurant landing page designed to showcase an authentic halal cuisine experience. Built using pure HTML, CSS, and JavaScript, this project offers a delightful digital representation of a vibrant restaurant that highlights its exquisite menu and commitment to quality.

## ✨ Features

- 🍲 **Stunning Menu Showcase**
  - Interactive menu grid with 12 mouth-watering dishes
  - High-quality food images
  - Transparent pricing
  - Hover effects that bring dishes to life

- 🏠 **Responsive Design**
  - Fully mobile-friendly layout
  - Adaptive navigation with hamburger menu
  - Smooth scrolling and intuitive user experience

- 📍 **About Us Section**
  - Restaurant origin story
  - Certifications and quality commitments
  - Embedded Google Maps location

- 🎨 **Modern UI/UX**
  - Warm color palette
  - Elegant typography
  - Subtle animations and transitions
  - Scroll-to-top functionality

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
- Font Awesome Icons
- Responsive Design Techniques

## 🌟 Key Highlights

- 100% Halal Certified
- FSSAI Approved
- 5-Star Hygiene Rated
- Located in the heart of Yelahanka, Bangalore

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No additional installations required!

### Installation
1. Clone the repository
2. Open `index.html` in your browser
3. Explore the delicious world of Halal Delights! 🍽️

## 📱 Responsive Breakpoints

- **Desktop:** Full layout
- **Tablet:** Adaptive layout
- **Mobile:** Compact, easy-to-navigate design

## 🔧 Customization

Feel free to:

- Modify color schemes in `styles.css`
- Update menu items in `index.html`
- Adjust JavaScript interactions in `script.js`
